# korea-law

대한민국의 모든 법령을 Git 저장소로 관리합니다.

- 모든 법령은 **Markdown 파일**
- 모든 개정은 **Git 커밋**

## 구조

```
├── 법률/          # 국회 제정 법률
├── 대통령령/      # 시행령
├── 총리령/        # 총리령
├── 부령/          # 시행규칙
├── 헌법/          # 헌법
└── ...            # 대법원규칙, 국회규칙 등
```

## 파일 형식

각 법령은 YAML frontmatter가 포함된 Markdown 파일입니다.

```markdown
---
법령명: "민법"
법령구분: "법률"
공포일자: "2024-01-01"
시행일자: "2024-07-01"
소관부처: "법무부"
출처: "https://www.law.go.kr/법령/민법"
---

# 민법

###### 제1조 (법원)
민사에 관하여 법률에 규정이 없으면 관습법에 의하고 ...
```

## 사용법

```bash
# 특정 법령의 개정 이력 확인
git log -- "법률/민법.md"

# 특정 개정에서 무엇이 변경되었는지 확인
git diff HEAD~1 -- "법률/민법.md"

# 특정 키워드가 포함된 법령 검색
grep -rl "개인정보" 법률/
```

## 데이터 출처

모든 법령 텍스트는 [법제처 국가법령정보센터](https://www.law.go.kr/)의 Open API에서 가져온 공공저작물입니다.

수집/변환 도구: [korea-law-script](https://github.com/yjroot/korea-law-script)

## 라이선스

법령 텍스트는 대한민국 공공저작물로 자유롭게 이용할 수 있습니다 ([공공누리](https://www.kogl.or.kr/)).
